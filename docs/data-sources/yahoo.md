# Yahoo Finance

Free equities, ETFs, indices, and commodities data.

**Source:** `yahoo` | **Credentials:** Not required

## Example

```json
{
    "tickerlist": ["AAPL", "MSFT", "GOOGL"],
    "start": "2025-01-01",
    "end": "2025-06-01",
    "interval": "1d",
    "source": "yahoo"
}
```

## Ticker Format

Standard Yahoo Finance symbols: `AAPL`, `MSFT`, `^GSPC` (S&P 500), `GC=F` (Gold Futures), `EURUSD=X`
