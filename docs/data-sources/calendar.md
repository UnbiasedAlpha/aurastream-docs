# Calendar

Earnings and economic calendar events.

**Source:** `calendar` | **Credentials:** Not required

## Example

```json
{
    "tickerlist": null,
    "start": "2021-01-01",
    "end": "2025-01-10",
    "interval": "1d",
    "source": "calendar"
}
```

!!! note
    Set `tickerlist` to `null` to fetch the full calendar. You can also pass specific ticker symbols to filter.
