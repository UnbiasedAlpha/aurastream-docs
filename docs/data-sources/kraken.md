# Kraken

Crypto futures data.

**Source:** `kraken` | **Credentials:** Not required

## Example

```json
{
    "tickerlist": ["PF_ETHUSD"],
    "start": "2025-01-01",
    "end": "2025-01-10",
    "interval": "1d",
    "source": "kraken"
}
```

## Ticker Format

Kraken futures symbols: `PF_ETHUSD`, `PF_XBTUSD`, `PI_ETHUSD`
