# dYdX

Decentralized perpetual exchange data.

**Source:** `dydx` | **Credentials:** Not required

## Example

```json
{
    "tickerlist": ["BTC-USD", "ETH-USD"],
    "start": "2025-01-01",
    "end": "2025-01-10",
    "interval": "1d",
    "source": "dydx"
}
```

## Ticker Format

dYdX format with dash: `BTC-USD`, `ETH-USD`, `SOL-USD`
