# Lyra

Decentralized options protocol data.

**Source:** `lyra` | **Credentials:** Not required

## Example

```json
{
    "tickerlist": ["BTC", "ETH"],
    "start": "2025-01-01",
    "end": "2025-01-10",
    "interval": "1d",
    "source": "lyra"
}
```

## Ticker Format

Base asset symbols: `BTC`, `ETH`
